# Spec Delta

## Purpose

定义个人品牌站的「关于我」区域：在 Hero 与 Projects 之间展示个人照片、三段个人简介与品牌标签，并在不同屏幕尺寸、主题与图片加载失败时保持可用与可读。

## ADDED Requirements

### Requirement: 关于我区域的位置与布局

系统 SHALL 在 Hero 与 Projects 之间渲染「关于我」区域，保留锚点 `id="about"` 与固定导航栏所需的滚动偏移，并使用二级标题「关于我」。桌面端 SHALL 为左侧照片、右侧简介的两栏布局；窄屏 SHALL 改为上下堆叠。

#### Scenario: 桌面端两栏布局

- **GIVEN** 访客在桌面宽度打开页面
- **WHEN** 滚动到「关于我」区域
- **THEN** 照片位于左侧、简介位于右侧，两者垂直居中，标题完整可见

#### Scenario: 移动端堆叠

- **GIVEN** 视口宽度为 375px
- **WHEN** 访客浏览「关于我」区域
- **THEN** 照片在上、简介在下，内容无水平溢出

#### Scenario: 区块顺序

- **GIVEN** 页面完整渲染
- **WHEN** 访客从 Hero 向下滚动
- **THEN** 先出现「关于我」区域，再出现项目展示区

### Requirement: 个人照片与加载降级

系统 SHALL 在区域左侧展示个人照片，使用本地资源与 `loading="lazy"`，预留固定宽高比以避免布局偏移，并提供描述性 `alt` 文本。照片加载失败时，系统 MUST 显示占位块并保持两栏布局稳定。

#### Scenario: 照片正常展示

- **GIVEN** 照片资源可用
- **WHEN** 访客滚动到「关于我」区域
- **THEN** 照片按预留比例显示，`alt` 可被辅助技术读取

#### Scenario: 照片加载失败

- **GIVEN** 照片资源返回失败
- **WHEN** 区域渲染
- **THEN** 照片位置显示占位块，简介与品牌标签不受影响，布局不塌陷

### Requirement: 三段个人简介

系统 SHALL 在照片右侧渲染恰好 3 段个人简介文本，按数据顺序展示。文本 MUST 在窄屏与桌面宽度下正常换行，不得溢出容器或产生水平滚动条。

#### Scenario: 展示三段简介

- **GIVEN** 简介数据包含 3 段文本
- **WHEN** 区域渲染
- **THEN** 三段文本按顺序完整显示

#### Scenario: 文本过长

- **GIVEN** 某段简介显著长于常规内容
- **WHEN** 在 375px 与桌面宽度下渲染
- **THEN** 文本正常换行，不溢出容器，不产生水平滚动条

#### Scenario: 简介数量异常

- **GIVEN** 简介数据少于 3 段
- **WHEN** 区域渲染
- **THEN** 页面正常渲染现有段落，不出现空占位或 `undefined` 文本

### Requirement: 品牌标签与无障碍

系统 SHALL 在照片与简介下方展示品牌标签「快乐蜂」。区域 SHALL 使用语义化结构（`section` + `h2`），并保证在明亮与暗黑主题下文字可读、对比度满足 WCAG AA。区域 MUST NOT 包含联系表单。

#### Scenario: 品牌标签展示

- **GIVEN** 区域已渲染
- **WHEN** 访客查看照片与简介下方
- **THEN** 可见文本「快乐蜂」，在两种主题下均可读

#### Scenario: 屏幕阅读器读取顺序

- **GIVEN** 访客使用屏幕阅读器
- **WHEN** 浏览「关于我」区域
- **THEN** 依次识别区块标题、照片描述、三段简介与品牌标签

#### Scenario: 不包含表单

- **GIVEN** 访客浏览「关于我」区域
- **WHEN** 使用 Tab 键遍历交互元素
- **THEN** 区域内不存在输入框、提交按钮或表单
